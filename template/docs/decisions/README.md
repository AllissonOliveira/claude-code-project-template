# Decisões (ADR)

Uma decisão importante por arquivo, numerada em sequência: `0001-titulo-curto.md`.
Um arquivo nunca é editado depois de aceito. Se a decisão mudar, crie uma nova e marque a antiga como substituída.
Use /new-decision para criar no formato certo.

## Formato

```markdown
# NNNN. <Título da decisão>

Data: YYYY-MM-DD
Status: aceita | substituída por NNNN

## Contexto
<O problema e as opções consideradas.>

## Decisão
<O que foi escolhido.>

## Consequências
<O que isso facilita, o que dificulta.>
```
