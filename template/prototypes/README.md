# Protótipos

Experimentos para responder uma pergunta: uma tela, uma técnica, uma integração.

- Uma subpasta por protótipo, cada uma com um README no formato abaixo.
- O código em src/ nunca importa daqui.
- Depois de concluído, o protótipo fica congelado: não é mais editado.
- Use /new-prototype para criar no formato certo.

## Formato do README

```markdown
# <Nome do protótipo>

Pergunta: <O que este protótipo quer responder.>
Resultado: <O que descobrimos.>
Status: em andamento | concluído (congelado) | descartado
Virou: <Decisão ou requisito que saiu daqui, se houver.>
```
